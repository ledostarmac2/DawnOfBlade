# Asset Credits & License Register

Every binary or third-party asset committed to this repository **must** be listed
here before it is used. This protects the project's "original / clean-license"
guarantee. If an asset is not in this table, it should not be in the repo.

## Rules

- Allowed licenses: original work (project license), **CC0**, **CC-BY** (with
  attribution kept in this file), **MIT**, or other clearly redistribution- and
  modification-permitting licenses.
- **Never** commit assets that are ripped from, imitate, or recreate proprietary
  games (including RuneScape / Jagex assets, cache files, names, maps, music,
  models, item/NPC data, or client/protocol code).
- For CC-BY assets, the attribution line below is what ships with the game; do
  not remove it.
