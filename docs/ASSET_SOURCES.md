# Asset Sources

The initial repository intentionally avoids third-party binary assets. This keeps the first commit small and avoids accidental license or provenance problems.

Acceptable future sources should be original, CC0, MIT, or otherwise compatible with the project license and documented at import time.

## Vetted Starting Points

- Kenney game assets: CC0-focused low-poly and UI packs. Check each pack license before import.
- OpenGameArt LowPoly RPG: CC0 low-poly fantasy/RPG-style assets. Check each asset page before import.
- OpenGameArt Low Poly Fantasy RPG Models: CC0 low-poly fantasy models.
- Godot Asset Library and Godot Asset Store: useful for Godot-ready packages, but verify each package license before import.

## Import Checklist

1. Confirm the license permits modification and redistribution.
2. Save the source URL, author, license, and import date.
3. Avoid assets that imitate or recreate proprietary games.
4. Commit only optimized assets needed by the current milestone.
5. Do not commit generated import caches from `.godot/`.
